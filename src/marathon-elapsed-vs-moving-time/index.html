Marathon Elapsed vs. Moving Time

At 30 km, a timer showing 2:50:00 with 2:00 excluded by pauses means 2:52:00 elapsed. For a 4:00 finish, the final 12.195 km need 5:34.56/km. Calculate (14,400 − 10,320) ÷ 12.195.

How much does ignoring two paused minutes change the answer?

Using 2:50:00 leaves 4,200 seconds and suggests 5:44.40/km. Using the full 2:52:00 leaves 4,080 seconds and gives 5:34.56/km. The difference is 9.84 seconds per kilometer. Running the first answer over 12.195 km would finish at 4:02:00.

What if I only know moving time?

Use a full elapsed-time field if available. A moving-time estimate can exclude periods according to the app's own rules. Add back a known difference only when both readings cover the same start and finish. For example, 3:58:00 moving plus a two-minute difference gives 4:00:00 elapsed.

What if the watch started before the start mat?

Align the starting point as well. If total elapsed reads 2:55:00 at 30 km and includes three minutes before crossing the mat, subtract those three minutes for 2:52:00 since the mat. This assumes your four-hour goal is measured between the start and finish mats.
