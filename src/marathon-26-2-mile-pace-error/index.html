Marathon Pace: The 26.2-Mile Distance Error

A 4:00 marathon pace calculated using 26.2 miles is 9:09.62/mi. Using 42.195 km gives 9:09.23/mi. Holding the unrounded 26.2-mile calculation over the full distance adds about 10.31 seconds.

Compare the two distance inputs

Use 1 mile = 1.609344 km. Dividing 42.195 by 1.609344 gives approximately 26.2187575 miles. Divide target seconds by each distance. The final column multiplies the unrounded 26.2-mile pace by the full converted distance, then subtracts the goal.

How far short is 26.2 miles?

Multiply 26.2 by 1.609344 for 42.1648128 km. Subtract this from 42.195 km for 0.0301872 km, or 30.1872 meters. This is a distance-input difference, independent of any watch measurement error.

Does rounding the displayed pace introduce another difference?

Yes. The table isolates the distance input by retaining unrounded paces during multiplication. If you then round 9:09.62 to 9:10 per mile, the extra rounding changes the projection again. Multiply the displayed 550 seconds by 26.2187575 miles for about 4:00:20.32.

Which input should I use in a marathon pace chart?

Use 42.195 km or its full mile conversion for the calculation. You can display 26.2 miles as a familiar short label while preserving the complete distance in the arithmetic. Keep the original pace value for calculating cumulative splits.
